# Atelier Électricité

Application web mobile pour réviser les calculs et les équations d’électricité sous forme de QCM.

## Fonctionnalités

- Loi d’Ohm
- Charge électrique
- Puissance électrique
- Mode équations
- Affichage facultatif des aides
- Installation sur mobile et fonctionnement hors connexion
